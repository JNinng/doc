# 注释标准
对代码注释的清理增加约束。补简注（[SKILL.md](../SKILL.md) 判别 3）时同样遵循本标准的分层上限。
下面“文档”通常指 Markdown

## 分层目标态（默认上限，可被用户数值覆盖）
| 层级      | 默认上限 | 应承载                                 |
| --------- | -------- | -------------------------------------- |
| 包/类型级 | ≤10 行   | 职责、边界、不变量                     |
| 函数级    | ≤6 行    | 契约：前置条件、后置条件、错误、副作用 |
| 行间      | ≤4 行    | 块代码简述、仅代码推不出的"为何"       |

- 行数口径：非空注释行计入；格式化标记（如 doxygen `@param`）、续行不计入。
- 层级归属：紧邻声明的注释归函数级；文件头、类/接口注释归包/类型级；语句块内归行间。

## 归属与指针
- 代码推不出的契约：留注释内并指向对应文档；
  注释保留本地必需的最小契约，完整正文归文档。
- 超限是"正文迁文档"的触发条件，不是压缩理由。
- 无对应文档时：去向（新建/迁他处/暂留超限）列入清理计划交裁决。

## 豁免
以下不计入上限、不处理：
- 法律声明、license 头、版权标注；
- 生成代码文件的机器头（注明生成器与版本）；
- 用户已声明的其他豁免范围（沿用 [SKILL.md](../SKILL.md) 边界）。

## 报告与验证
- 超限/复述注释在标记报告中注明层级与行数，归类沿用 [SKILL.md](../SKILL.md)。
- 验证增加：重写后注释均满足上限或已列入迁移计划；
  指针指向的文档目标存在（纳入死链检查）。
